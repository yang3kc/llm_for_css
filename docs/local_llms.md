# Running LLMs locally

This chapter is under construction.

It will cover running open-weight models on your own machine: no API key, no per-token cost, and your data never leaves your computer.
This matters for computational social science when you work with sensitive data or want full control over the model version for reproducibility.

In the meantime, the [open-source models](open_source_models.ipynb) chapter shows how to use the same family of models through a hosted API.
